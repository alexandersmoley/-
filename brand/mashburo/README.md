# Машбюро — знаки

Восемь аватарок без текста, по одной на дизайн-стиль. Отсюда растёт фирстиль:
знак, палитра, паттерн.

## Что где

- `avatars/*.svg` — исходники, 512×512. Правки вносим здесь
- `avatars/png/*.png` — растр 512×512, пересобирается из SVG
- `znaki.html` — страница сравнения: круглый кроп, размеры 96/48/28, палитра, рекомендация

## Палитра

| Цвет | Код | Где |
|---|---|---|
| Чернильная | `#14110F` | знак, заголовки, текст |
| Бумага | `#F2ECE1` | фон знаков и макетов |
| Лента | `#C8402E` | правка, акцент, один элемент в макете |

Красный — вторая половина ленты печатной машинки. Работает, пока его мало.

## Пересобрать PNG

```sh
cd avatars
for f in *.svg; do
  /opt/pw-browsers/chromium-1194/chrome-linux/chrome --headless --no-sandbox \
    --window-size=512,512 --screenshot=png/${f%.svg}.png "file://$PWD/$f"
done
```

## Что не сделано

- Упрощённые версии для мелких размеров: валик, гравюра, матрица слипаются на 24 px
- Шрифтовая пара для написания имени рядом со знаком
- Палитра генератора каруселей (`content/karusel-2027`) пока другая
- Проверка на занятость: домен, ники, Роспатент по классам 35 и 41
