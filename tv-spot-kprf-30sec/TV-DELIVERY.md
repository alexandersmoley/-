# Сдача на телеканал

> Требования канала лежат в папке «Загрузки» вместе с фонограммой и фирстилем —
> в это окружение она не смонтирована. Ниже — типовые требования российского
> регионального эфира. **Сверить с файлом заказчика до отправки**, расхождения
> исправляются параметрами в `build/assemble.sh`.

## Видео

| Параметр | Значение | Где задаётся |
|---|---|---|
| Разрешение | 1920×1080 | `render.sh`, `assemble.sh` |
| Развёртка | прогрессивная, 25 к/с (`1080p25`) | `--fps` |
| Соотношение сторон | 16:9, квадратный пиксель (SAR 1:1) | — |
| Кодек мастера | ProRes 422 HQ, 10 бит, 4:2:2 | `-c:v prores_ks -profile:v 3` |
| Контейнер | MOV | — |
| Цвет | Rec. 709, уровни TV (16–235) | см. «Вещательная безопасность» |
| Хронометраж | ровно 30,000 с (750 кадров) | `build/timeline.txt` |

Если канал просит **XDCAM HD422 50 Мбит/с в MXF** — самый частый вариант для эфира:

```bash
ffmpeg -i output/kprf_30sec_master.mov \
  -c:v mpeg2video -b:v 50M -minrate 50M -maxrate 50M -bufsize 17825792 \
  -pix_fmt yuv422p -flags +ildct+ilme -top 1 -r 25 \
  -c:a pcm_s24le -f mxf_d10 output/kprf_30sec_xdcam.mxf
```

Если просят H.264 MP4 — годится `output/kprf_30sec_preview.mp4`, но битрейт
обычно поднимают до 15–25 Мбит/с (`-b:v 20M` вместо `-crf 18`).

## Звук

| Параметр | Значение |
|---|---|
| Частота дискретизации | 48 кГц |
| Разрядность | 24 бита (PCM), мастер без сжатия |
| Каналы | стерео; при моно-начитке — одинаковый сигнал в оба канала |
| Громкость | −23 LUFS ±1 (EBU R128) |
| True peak | не выше −1 dBTP |
| Музыка | отсутствует по заданию — только голос |

`assemble.sh` прогоняет фонограмму через `loudnorm=I=-23:TP=-1:LRA=7` и кладёт
замер в `output/loudness.txt`. Если канал требует −24 LUFS (ATSC A/85) —
поменять `I=-23` на `I=-24`.

## Вещательная безопасность

- **Title-safe 90 %** — весь текст и логотип внутри. В заставке отступы уже
  заданы (96 px по горизонтали, 54 px по вертикали).
- **Уровни.** Мастер должен быть в TV-диапазоне. Если канал отбраковывает по
  превышению, добавить в цепочку `scale=in_range=full:out_range=tv`.
- **Насыщенный красный.** Фирменный красный на плашках — самый рискованный цвет
  для эфира: на слабом тракте он «течёт» по краям. Держать его как заливку крупных
  плоскостей, не пускать в тонкие линии и не класть на него мелкий текст.
- **Никакого стробоскопа.** Плавный наезд вместо резких вспышек — заодно снимает
  вопрос по эпилептической безопасности.

## Поля до и после

Многие каналы просят «оболочку» вокруг ролика:

- 2 с чёрного + тишина в начале и в конце, либо
- 10 с цветных полос и тона −18 dBFS перед роликом.

По умолчанию `assemble.sh` отдаёт **чистые 30 секунд без полей** — так почти всегда
и просят. Если нужна оболочка:

```bash
ffmpeg -i output/kprf_30sec_master.mov -f lavfi -t 2 -i color=black:s=1920x1080:r=25 \
  -f lavfi -t 2 -i anullsrc=r=48000:cl=stereo \
  -filter_complex "[1:v][2:a][0:v][0:a][1:v][2:a]concat=n=3:v=1:a=1[v][a]" \
  -map "[v]" -map "[a]" -c:v prores_ks -profile:v 3 -c:a pcm_s24le output/kprf_30sec_with_slate.mov
```

## Чек-лист перед отправкой

- [ ] Хронометраж ровно 30,000 с
- [ ] Громкость −23 LUFS ±1, true peak ≤ −1 dBTP
- [ ] Весь текст в title-safe
- [ ] Логотип — официальный из фирстиля, не заглушка
- [ ] Слоган и дата совпадают с утверждённой кампанией
- [ ] Формат и оболочка — по требованиям конкретного канала
- [ ] Файл назван по шаблону канала (обычно `Заказчик_Название_30sec_ДДММГГ`)
