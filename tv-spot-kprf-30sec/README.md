# ТВ-ролик КПРФ, 30 секунд

Ролик под фонограмму: дубль с **02:25 до конца** исходной записи, хронометраж **30 сек**,
**без музыки** — только голос. Видеоряд: цветные иллюстрации по теме, в финале —
заставка на основе фирменного стиля со слоганом.

## Что в папке

```
assets/illustrations/*.svg   исходники иллюстраций (векторы, правятся руками)
assets/endcard/endcard.html  заставка: токены фирстиля вынесены в :root
render/render.sh             SVG/HTML → PNG 1920×1080
build/timeline.txt           раскадровка: кадр + длительность (сумма = 30.000)
build/assemble.sh            фонограмма + кадры → мастер ProRes и превью H.264
output/frames/*.png          отрендеренные кадры (лежат в репозитории для сверки)
script-30sec.md              тайминг-лист и экранный текст
TV-DELIVERY.md               требования к сдаче на телеканал
```

## Как собрать

```bash
./render/render.sh                                  # кадры → output/frames
./build/assemble.sh --audio ~/Downloads/kprf.mp3    # → output/kprf_30sec_master.mov
```

`render.sh` использует Chromium (путь переопределяется переменной `CHROME`).
`assemble.sh` требует полноценный ffmpeg/ffprobe.

## Статус: черновик, три позиции заблокированы

Сборку финального файла **в этой среде выполнить нельзя** и часть решений принята
на допущениях. Подробности и что для этого нужно — в конце `script-30sec.md`,
раздел «Чего не хватает».

Коротко:

1. **Фонограммы нет.** Исходник лежит в локальной папке «Загрузки», в это окружение
   она не смонтирована. Тайминги в `build/timeline.txt` — предварительные,
   точки склейки ставятся по речи после получения дубля.
2. **Фирстиля нет.** PDF `gazeta3` недоступен, поэтому цвета, шрифт и логотип
   в заставке — реконструкция по газете «Оренбургская правда» № 7 (1044),
   логотип стоит заглушкой. Сверить и заменить по PDF.
3. **Требований телеканала нет.** `TV-DELIVERY.md` собран по типовым требованиям
   российского регионального эфира — сверить с файлом заказчика до сдачи.

Смысловая основа взята из утверждённого текста «ГАЗЕТА 3 — 2026» (Google Docs):
призыв голосовать 20 сентября, риск фальсификаций, наблюдение на участках.
