# Design brief — первый закреп

## Задача

Сделать одиночный Instagram post 1080×1350, который знакомит с автором и одновременно становится первым эталоном дизайн-системы контент-завода.

## Контент обложки

Основной текст: **«Привет, я Саша Смолей»**.

`КТО Я` — необязательный eyebrow: оставить только если усиливает композицию.

Не помещать на обложку длинное описание блога. Оно живёт в подписи поста.

## Обязательные Canva assets

Использовать только эти материалы. Не заменять их Canva stock, генерацией или похожими изображениями.

### Исходное фото

- `alexsmoley-photo-chair`
- Canva asset ID: `MAHTX_B6J9k`
- Это единственная разрешённая фотография для первого закрепа.
- Не перерисовывать, не менять лицо, внешность и одежду.

### Визуальные референсы

1. `alexsmoley-reference-01` — asset ID `MAHTX_X8-OI`
2. `alexsmoley-reference-02` — asset ID `MAHTX9HScio`
3. `alexsmoley-reference-03` — asset ID `MAHTXzaCKC0`
4. `alexsmoley-reference-04` — asset ID `MAHTX8uYNbo`

Это не контент для вставки в финальный пост. Это референсы композиции, типографической иерархии, сетки, использования синего и общего редакционного характера.

## Визуальная база

- Опираться на стиль alexsmoley.ru и четыре Canva-референса выше.
- Редакционная журнальная композиция, а не типовой social-media template.
- Фото и типографика могут пересекаться.
- Фирменный синий — структурный акцент, а не автоматически огромная плашка.
- Сетка — тонкая и функциональная.
- Сначала воспроизвести систему референсов, затем адаптировать её под одиночный закреп.

## Типографика

- Заголовок: Cormorant Garamond Regular; Italic только как осознанный акцент.
- Служебный текст: Inter Regular.

## Не делать

- использовать другое фото;
- использовать Canva stock вместо исходного фото;
- генерировать человека/портрет;
- стрелки без функции;
- прогресс-бары одиночного поста;
- декоративные подписи по одному слову;
- URL на обложке без задачи;
- псевдологотипы и иконки;
- дополнительные тезисы, которые пользователь не согласовал;
- белый текст на светлом участке фотографии без контрастной подложки/обработки.

## Критерий готовности мастер-макета

Пользователь должен сначала утвердить композицию как дизайн. Только после этого слои размечаются как динамические поля и шаблон включается в автоматизацию.
