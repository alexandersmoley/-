# Brief for Codex — alexsmoley Content Factory

Ты работаешь над производственной системой личного Instagram `alexsmoley`. Это пилот будущей услуги по внедрению контент-заводов брендам.

## Source of truth

Перед работой прочитай все файлы в `instagram-factory/`. Не восстанавливай правила фирстиля по памяти и не придумывай недостающие дизайн-решения молча.

## Главная задача на ближайший спринт

Доказать полный production loop на одном закреплённом посте.

1. Найти/создать в Canva мастер-дизайн 1080×1350.
2. Реализовать бриф `design-brief-pinned-post.md`.
3. Использовать настоящую фотографию пользователя и точные фирменные шрифты/цвета. Если точные HEX не подтверждены — сначала извлечь их из исходного сайта/дизайна и зафиксировать в `brand-system.md`.
4. Не использовать Canva AI generation для финального дизайна. Нужен контролируемый редактируемый мастер-макет.
5. После утверждения пользователя превратить разрешённые элементы в динамические поля/autofill, если Canva-коннектор это поддерживает.
6. Подготовить повторяемый путь: structured content → Canva template → export → publishing queue.

## Жёсткие ограничения

- Никаких самовольных декоративных слов и подписей.
- Не менять font family на похожий.
- Не добавлять стрелки/навигацию без функции.
- Не менять лицо/внешность на фото.
- Не публиковать без явного approval на этапе MVP.
- Не хранить секреты/API keys в репозитории.
- Не коммитить файлы шрифтов без проверки лицензии.

## Definition of Done первого этапа

- один визуально утверждённый мастер-макет;
- его поля определены и документированы;
- из тестовых данных можно получить новый вариант без ручной перевёрстки;
- готовый asset можно передать в очередь публикации;
- весь процесс описан так, чтобы повторить его для клиента.
