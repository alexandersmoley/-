# Visual references — alexsmoley

## Зачем нужен этот слой

`visual-references/` — база визуального вкуса для Instagram `alexsmoley`.

Она не является коллекцией готовых картинок для копирования. Это слой арт-дирекшена: сюда попадают внешние референсы из Pinterest, Cosmos, сайтов, журналов и других публичных источников, чтобы production не «придумывал красиво» из воздуха.

Главная задача: перед каждым визуальным production отвечать не на вопрос «что нарисовать?», а на вопрос **«какие конкретные визуальные приёмы подходят этой мысли?»**.

## Принцип использования

Правильный путь:

`идея → смысл → 3–5 референсов → разбор, что именно берём → собственная композиция → renderer → QA`

Неправильный путь:

`нашли красивую картинку → сделали почти так же`

## Что можно забирать из референса

Можно фиксировать и использовать как направление:

- композиционный принцип;
- соотношение текста и изображения;
- ритм и плотность;
- крупность фотографии;
- пустое пространство;
- кадрирование;
- типографическую иерархию;
- характер сетки;
- работу с линиями и схемами;
- фактуру;
- фотографический приём;
- монтажный ритм для Reels;
- способ перехода между сценами;
- общий уровень визуальной дерзости/сдержанности.

## Что нельзя

- автоматически использовать чужое изображение в публикации только потому, что оно найдено в Pinterest/Cosmos;
- перерисовывать чужую работу один в один;
- копировать уникальную композицию с минимальными изменениями;
- использовать изображения с неясными правами как production assets;
- считать Pinterest/Cosmos фотостоком;
- добавлять чужой логотип, watermark или авторскую графику в финальный макет;
- использовать референс как разрешение на публикацию.

Если нужен внешний asset для финального материала, права/лицензия должны быть понятны отдельно.

## Структура

- `editorial-photography.md` — фотография, кадрирование, документальность, портреты, предметка.
- `typography-layouts.md` — editorial-типографика, композиции, сетки, обложки.
- `industrial-language.md` — промышленная/техническая эстетика, когда она реально помогает метафоре контент-производства.
- `motion-reels.md` — кинетическая типографика, схемы, переходы, ритм Reels.
- `reference-template.md` — формат добавления конкретного референса.

## Как использовать в production brief

В каждом brief, где внешние референсы действительно нужны, добавляется блок:

```yaml
visual_references:
  - source: "Pinterest | Cosmos | website | magazine"
    url: "..."
    use_for: "что именно берём: например, асимметричную композицию и крупный serif headline"
    do_not_copy: "конкретная фотография, иллюстрация, логотип, уникальный арт"
```

Референс без поля `use_for` не считается арт-дирекшеном.

## Важное правило вкуса

Не нужно превращать блог в Pinterest-moodboard.

Внешние референсы должны усиливать уже существующую визуальную систему `alexsmoley`, а не каждый раз менять стиль публикации.

Фирменная база остаётся в `brand-system.md` и `design-direction.md`.
