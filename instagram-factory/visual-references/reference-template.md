# Reference template

Use this structure for every external visual reference.

```yaml
id: ref-0001
source: Pinterest | Cosmos | website | magazine | other
url: "https://..."
source_title: "optional"
author_or_brand: "optional"
added_for: "post/reel/series/global"
rights_status: "reference-only | licensed | owned | unclear"

what_works:
  - "specific visual principle"
  - "specific composition or motion principle"

use_for:
  - "what may influence our original production"

do_not_copy:
  - "specific image/artwork/logo/composition that must not be reproduced"

notes: "optional"
```

## Required minimum

A valid reference must have:

- `source`;
- `url`;
- `rights_status`;
- at least one concrete item in `what_works`;
- at least one concrete item in `use_for`.

“Красиво”, “стильно”, “вайб” without explanation are not sufficient.
