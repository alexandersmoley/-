# Реел — одна тема на три площадки

## Задача

Показать результат одного прогона: что вышло на трёх площадках из одной фактуры и где
всё ещё нужен человек. Не инструкция по настройке — этот реел уже был. Здесь итог.

Обещание одной фразой: за 36 секунд зритель понимает, чем три материала отличаются друг
от друга и почему публикация в каждом канале устроена по-своему.

Без лица, без озвучки. Три канала — три пронумерованных кадра, номер работает как график.

## Тон

Обязателен `writing-contract.md`. Конкретные вещи вместо абстракций: не «интеграции», а
Metricool и браузер. Цифра 404 остаётся цифрой. В каждом заголовке один фрагмент набран
курсивом — он объявлен блоком «Курсив», а не выбирается рендером.

## Подтверждённые факты

Фактура целиком берётся из `topics/one-topic-three-channels-master-brief.md`. Здесь
повторяются только те, что попадают на экран:

- источник фактов один, тексты для каналов разные, копипаста запрещена правилами проекта;
- Instagram уходит через Metricool по API;
- у vc.ru нет публичного эндпоинта создания записи: 404 на восьми проверенных путях;
- Telegram и vc.ru публикуются через браузер;
- сборка макета падает при расхождении с утверждённым текстом;
- три дефекта в этом прогоне нашлись глазами при зелёных проверках;
- человеческих решений остаётся четыре.

# Caption

Попросил Claude Code взять одну тему и сделать материалы сразу для Instagram, Telegram и vc.ru. Этот реел — один из трёх.

Источник фактов один, тексты разные: копипасту между каналами правила проекта запрещают.

Интереснее всего оказалась публикация. Instagram уходит через Metricool по API. С vc.ru я рассчитывал так же и ошибся: публичного эндпоинта для создания записи там нет — проверил, 404 на восьми путях, при том что тот же API честно отвечает 401 там, где дело в токене. Значит пути просто нет. Туда и в Telegram — через браузер.

Макеты собирает рендерер проекта, и сборка падает, если отрисованные слова разошлись с утверждённым текстом, не загрузились шрифты или подпись вылезла из блока.

Но три дефекта я нашёл глазами при зелёных проверках: у стрелок наконечники висели отдельно от древка, черновик на обложке заполнялся снизу вверх, а баннер аккаунта на узком кропе терял всю мысль картинки.

Гейты ловят технику и не ловят смысл. Поэтому четыре решения пока мои: тема, текст, дизайн, публикация.

Разбор целиком — в статье на vc.ru, рабочая записка — в Telegram.
