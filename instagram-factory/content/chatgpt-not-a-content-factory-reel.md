# Core idea

Показать один цикл: сначала я собираю контент-план в ChatGPT и сохраняю его в Todoist. Потом беру одну тему и веду её через ChatGPT → GitHub → Codex → публикацию → аналитику → обратно в ChatGPT.

Главная связь: **ChatGPT — редакционная работа, GitHub — source of truth, Codex — производство.**

# Music

Музыка обязательна.

- Инструментальная электронная.
- Без вокала.
- Ориентир: 100–120 BPM.
- Собранная, техничная, без эпика и корпоративной мотивационной музыки.
- Сначала выбрать трек/BPM, потом под него выставить точные тайминги сцен.
- Появление этапов синхронизировать с битом.
- Переход ChatGPT → Todoist → ChatGPT → GitHub → Codex вести в ритм.
- Каждый синий ОК — отдельный музыкальный акцент.
- Финальную схему показать на самом плотном участке трека.
- Использовать только музыку, которую можно законно использовать в Instagram. Если renderer не может получить лицензированный трек автоматически, использовать временный instrumental guide track и отдельно указать параметры трека для замены перед публикацией.

# Acceptance criteria

- 1080×1920, 25 секунд.
- Без скринов, озвучки и talking head.
- Контент-план сначала создаётся в ChatGPT, затем хранится в Todoist.
- В работу идёт одна тема из плана.
- Связка ChatGPT → GitHub ← Codex читается сразу.
- GitHub хранит утверждённый контекст и brief.
- Codex собирает материал после редакционной работы в ChatGPT.
- Синим выделены четыре человеческие точки: тема, текст, дизайн, публикация.
- Публикация происходит только после "ОК — публикация".
- Аналитика возвращается в ChatGPT и замыкает цикл.
- Музыка задаёт ритм монтажа.
- Cover собран отдельно.
- Ничего не публиковать без отдельного ОК.
