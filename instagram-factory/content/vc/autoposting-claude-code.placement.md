# Куда какая картинка идёт

Четыре файла к статье «Как я собрал себе контент-завод на ChatGPT и Codex».
Все 1920×1080, PNG, отрендерены фирменным рендерером проекта.

Источник истины — `content/vc/autoposting-claude-code.publication.json`, поле `placement`
у каждого визуала. Этот файл — то же самое человеческими словами.

## 1. cover.png — в поле «Обложка», не в текст

`output/vc/autoposting-claude-code-vc/cover.png`

Пять стадий производства во всю высоту кадра, без текста. Заголовок vc.ru показывает
рядом сам, поэтому на обложке слов нет — она должна работать превью в ленте, а не читаться.

**Ставить:** в поле обложки публикации. В тело статьи не вставлять.

## 2. workflow.png — после раздела «Что я называю контент-заводом»

`output/vc/autoposting-claude-code-vc/workflow.png`

Весь маршрут материала: десять стадий на одной линии, синим — четыре решения, которые
принимает человек.

**Ставить:** сразу после абзаца «Конкретные сервисы со временем наверняка поменяются.
Меня больше интересует сама схема.» — то есть перед «Шаг 1».

**Подпись:** Весь маршрут целиком. Синие блоки — четыре решения, которые я принимаю сам.

## 3. chatgpt-github-codex.png — в «Шаг 4»

`output/vc/autoposting-claude-code-vc/chatgpt-github-codex.png`

Две рабочие зоны и общий архив между ними: слева редактура, справа производство,
в центре синим — то, что зафиксировано в GitHub.

**Ставить:** в разделе «Шаг 4. ChatGPT и Codex связывает GitHub», сразу после строки
со схемой `ChatGPT → GitHub ← Codex`.

**Подпись:** То же самое подробнее: что лежит в GitHub и что каждая сторона оттуда берёт.

## 4. multichannel.png — в «Следующий этап»

`output/vc/autoposting-claude-code-vc/multichannel.png`

Один утверждённый бриф расходится в четыре формата: Instagram, vc.ru, Telegram, блог.

**Ставить:** в разделе «Следующий этап — несколько каналов из одной темы», сразу после
строки со схемой `одна тема → главный бриф → Instagram / vc.ru / Telegram / блог`.

**Подпись:** Куда это идёт дальше: один бриф — несколько самостоятельных материалов.

## Порядок в теле статьи

`workflow` → `chatgpt-github-codex` → `multichannel`. Обложка вне этого порядка.

Порядок не декоративный: первая схема даёт маршрут целиком, вторая разбирает его середину,
третья показывает, куда всё это идёт дальше. Если менять местами — читатель увидит частность
раньше общего.
