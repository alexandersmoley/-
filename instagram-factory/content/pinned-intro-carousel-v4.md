# Закреп — факты обо мне

## Задача

Главный закреп строится как простое знакомство: обложка → один реальный факт на один слайд → закрывашка.

Не объяснять позиционирование, не превращать карусель в резюме и не добавлять концептуальные формулировки от себя.

Каждый факт должен опираться только на подтверждённую биографию Саши.

## Визуальный принцип

- Один слайд = одно фото + один факт.
- Фото реальные, из фотобанка пользователя на Google Drive.
- Не перерисовывать лица и не генерировать внешность.
- Не использовать fake UI, AI-декор, роботов, sparkles, декоративные слова и бессмысленные стрелки.
- Фирстиль: alexsmoley.ru / brand-system.md / design-direction.md.
- Editorial / web-magazine композиция, Inter + Cormorant Garamond, фирменный синий + светлый/молочный + чёрный.
- Обложка должна работать в thumbnail профиля.
- Композиции можно варьировать, но серия должна ощущаться одной системой.

## Источник фотографий

Основной фотобанк:
https://drive.google.com/drive/folders/1iQcFguCF6l2yrTtlKIOR4TlId-omShWL

Подбирать фото по смыслу конкретного факта. Не использовать один кадр повторно без причины.

Для слайда про сына приоритет — живое семейное фото. Для путешествий — реальный кадр из поездки. Для удалёнки — реальная рабочая сцена, если она есть в фотобанке. Для деревни/первой работы не придумывать архивный кадр: если подходящего фото нет, использовать современный портрет/местность и дать факту работать текстом.

## Production rules

1. Использовать только exact copy выше.
2. Сначала подобрать реальные фото из Drive под каждый слайд.
3. Сделать thumbnail-preview обложки.
4. Отрендерить 8 карточек 1080×1440.
5. Собрать contact sheet.
6. QA: читаемость, safe area, контраст, кропы, отсутствие переписанного copy.
7. Остановиться на design-review.
8. publish остаётся false до отдельного подтверждения пользователя.
