# Реел — как устроен постинг от идеи до аналитики

## Задача

Объяснить процесс простыми словами и по шагам. Зритель должен понять механику с первого просмотра, не зная слов «рендер», «контрольная сумма» и «CI».

Ровно четыре шага, и они совпадают везде: в первом кадре, в нумерации сцен, в схеме на пятом кадре и на обложке. Todoist, GitHub, Claude Code, Metricool — четыре сервиса, четыре шага.

Без лица, без озвучки, без говорящей головы. Только текст, схемы и движение под музыку.

Это не обзор сервисов и не реклама инструментов. Это отчёт о собственном процессе, включая место, где он ломается.

## Тон

Обязателен `writing-contract.md`. Инфостиль: коротко, конкретно, без пафоса и без обещаний «автоматизируй всё за 5 минут».

Обиходные слова вместо технических: «робот» вместо «кодовый агент», «нельзя поменять незаметно» вместо «copy freeze», «пост не выйдет» вместо «красный прогон».

Ни одного факта, которого не было. Никаких выдуманных цифр, метрик и сроков.

## Темп

Шесть сцен по пять секунд. На кадре максимум три строки, из них одна крупная. Строки не длиннее одной мысли.

## Подтверждённые факты

- План и темы лежат в Todoist.
- Бриф, утверждённый текст и рендерер лежат в GitHub.
- Текст замораживается контрольной суммой: рендер сверяет её и падает при расхождении.
- Картинки рендерятся в CI, а не на машине автора.
- Публикацию выполняет Metricool.
- Аналитика возвращается в план.
- Человек принимает решение о публикации.
- Рил говорит только про то, как процесс устроен сейчас. Никакой предыстории: ни «перестал», ни «раньше делал руками», ни «только начал».

- "Пишу задачу → дальше всё сам"

- Стрелка в средней строке появляется после первого узла.

## Scene 02 — 5.0–10.0 sec

Текст:
- "Шаг 1. Записываю идею"
- "В обычный список дел — Todoist"
- "идея → задача в списке"

Motion:
- Список тем сжимается до одной строки.
- Выбранную задачу выделить.

## Scene 03 — 10.0–15.0 sec

Текст:
- "Шаг 2. Утверждаю текст"
- "Дальше его нельзя поменять незаметно — ни мне, ни роботу"

Motion:
- Схема собирается из двух сторон к центру.
- Центральный блок фиксируется и больше не двигается.

## Scene 04 — 15.0–20.0 sec

Текст:

Motion:
- Цепочка идёт вперёд по одному узлу.
- Последняя строка появляется как отдельная плашка, без резкого контраста.

## Scene 05 — 20.0–25.0 sec

Текст:

- "Todoist → GitHub → Claude Code → Metricool"
- "От меня — одно «ок»"

Motion:
- Сначала появляется плашка с «ок», затем под ней собирается полная схема из четырёх сервисов.

Текст:

Motion:

- Последняя строка остаётся на экране до конца.

# Cover

Собрать отдельно.

Без фотографии и без лица. Обложка типографская: крупный заголовок на тёмном поле, под ним цепочка из четырёх сервисов — тех же, что в кадре 5.

Текст:
- "Посты выкладываю не я"
- "Todoist → GitHub → Claude Code → Metricool"

# Music

Музыка обязательна. Инструментал без вокала, 100–120 BPM, ровный ритм без нарастания к финалу.

Озвучки нет. Говорящей головы нет.

# Caption

Кнопку «опубликовать» здесь нажимаю не я. Пишу задачу — дальше всё идёт само, а от меня остаётся одно «ок».

Шаг 1: идея попадает в обычный список дел, Todoist. Шаг 2: утверждённый текст ложится в GitHub, и после этого его нельзя поменять незаметно — ни мне, ни роботу. Шаг 3: Claude Code собирает картинки и сам себя проверяет: если что-то не сходится, пост просто не выйдет. Шаг 4: публикует Metricool.

Дальше я смотрю, что зашло, и из этих цифр берётся следующая идея.

Здесь показываю, как это устроено и что в нём ломается.

# Acceptance criteria

- 30 секунд, 1080×1920, 30 fps;
- шесть сцен по пять секунд, не больше трёх строк в кадре;
- четыре шага и четыре сервиса совпадают в первом кадре, в нумерации сцен, в схеме и на обложке;
- ни лица, ни голоса, ни говорящей головы;
- музыка присутствует, дорожка стерео;
- обложка читается в ленте без звука;
- последняя сцена содержит призыв подписаться;
- ни одного факта сверх подтверждённого списка;
- `publish: false` сохранён.
