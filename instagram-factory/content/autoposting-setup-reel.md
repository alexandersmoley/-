# Реел — как настроить автопостинг в Instagram

## Задача

Инструкция, которую зритель может повторить сегодня. Не рассказ о том, как устроен мой процесс.

Обещание одной фразой: после просмотра человек знает, какие четыре сервиса подключить, что в них положить и что написать, чтобы пост ушёл в Instagram без него.

Формат подсказан жанром: три шага, у каждого свой кадр, номер шага — главный графический элемент. Без схем и стрелок.

Без лица, без озвучки. Текст, крупные цифры и движение под музыку.

## Тон

Обязателен `writing-contract.md`. Императив вместо описания: «заведи», «подключи», «попроси». В каждом заголовке один фрагмент набран курсивом — он объявлен в бриф-файле блоком «Курсив», а не выбирается рендером. Работу делает Claude Code, и он назван по имени: не «он собирает», а «Claude Code собирает». Каждый шаг называет конкретную вещь, а не действие вообще.

## Подтверждённые факты

- Все четыре сервиса — отдельные аккаунты автора: Metricool, Todoist, GitHub и Google Drive. В Claude Code они подключены как коннекторы.
- Публикацию выполняет Metricool.
- План тем лежит в Todoist, тоже подключённом как коннектор.
- GitHub подключён как коннектор: там лежат бриф, утверждённый текст, правила тона и отобранные фото.
- Google Drive подключён как коннектор. Оригинал фотографии для закрепа автор держал именно там, оттуда её и забрали.
- Карусель-закреп действительно вышла в Instagram этим способом.
- Автор не писал код руками.
- Портрет в закрывающем кадре — присланный автором кадр `alexsmoley-portrait-blue`: вырезанный силуэт на синем поле, 640×640. Метаданные сняты, репозиторий публичный. Другое фото не использовать.
- Автопубликация в Instagram через сторонний сервис требует бизнес- или креатор-аккаунта. Это ограничение самого Instagram, а не Metricool.

## Чего в риле нет

- Обещаний экономии в часах, процентах и деньгах: ничего из этого не измерялось.
- Шагов, которых автор не делал.
- Объяснения архитектуры вместо шагов.

# Caption

Показываю, как настроить автопостинг в Instagram. Всё делается в чате Claude Code, программировать не нужно.

Шаг 1. Заводишь аккаунты в четырёх сервисах: Metricool, Todoist, GitHub и Google Drive. Instagram привязываешь к Metricool — через него Claude Code и будет публиковать. Аккаунт нужен бизнес или креатор: с личного автопубликация не работает, это ограничение самого Instagram.

Шаг 2. В настройках Claude Code подключаешь их как коннекторы: Metricool публикует, Todoist держит план тем, GitHub хранит материалы, Google Drive — фотографии. Это делается в интерфейсе, кода не нужно.

Шаг 3. Обсуждаешь тему прямо в чате: что за материал, какие факты, какой текст. Claude Code складывает это в бриф — файл в GitHub с темой, фактами, утверждённым текстом поста и правилами тона. Фото берёт из Google Drive.

Бриф — это то, из чего потом собирается пост. Дальше Claude Code рендерит только его: если текст в макете разойдётся с утверждённым хоть на символ, сборка падает и пост не выходит.

Дальше пишешь одну фразу: «Собери карусель по брифу и опубликуй в Instagram». Claude Code собирает, проверяет и публикует.

Платный здесь только Claude Code. Metricool, Todoist, GitHub и Google Drive работают на бесплатных тарифах.

Мой закреп вышел именно так. Здесь я строю контент-завод и показываю, что в нём ломается по дороге.

# Acceptance criteria

- 36 секунд, 1080×1920, 30 fps;

- четыре коннектора названы поимённо;
- сказано, что такое бриф и на каком шаге он появляется;

- действующее лицо на экране — Claude Code, а шаги сформулированы как просьбы к нему;

- Instagram написан латиницей везде, где его читает зритель;
- в каждом крупном заголовке ровно один курсивный фрагмент;
- в подписи сказано, что платный только Claude Code;
