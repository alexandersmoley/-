# Реел — как настроить автопостинг в инстаграм

## Задача

Инструкция, которую зритель может повторить сегодня. Не рассказ о том, как устроен мой процесс.

Обещание одной фразой: после просмотра человек знает, какие четыре сервиса подключить, что в них положить и что написать, чтобы пост ушёл в инстаграм без него.

Формат подсказан жанром: три шага, у каждого свой кадр, номер шага — главный графический элемент. Без схем и стрелок.

Без лица, без озвучки. Текст, крупные цифры и движение под музыку.

## Тон

Обязателен `writing-contract.md`. Императив вместо описания: «заведи», «подключи», «попроси». Работу делает Claude Code, и он назван по имени: не «он собирает», а «Claude Code собирает». Каждый шаг называет конкретную вещь, а не действие вообще.

## Подтверждённые факты

- Публикацию выполняет Metricool, подключённый как коннектор.
- План тем лежит в Todoist, тоже подключённом как коннектор.
- GitHub подключён как коннектор: там лежат бриф, утверждённый текст, правила тона и отобранные фото.
- Google Drive подключён как коннектор. Оригинал фотографии для закрепа автор держал именно там, оттуда её и забрали.
- Карусель-закреп действительно вышла в инстаграм этим способом.
- Автор не писал код руками.
- Автопубликация в инстаграм через сторонний сервис требует бизнес- или креатор-аккаунта. Это ограничение самого инстаграма, а не Metricool.

## Чего в риле нет

- Обещаний экономии в часах, процентах и деньгах: ничего из этого не измерялось.
- Шагов, которых автор не делал.
- Объяснения архитектуры вместо шагов.

# Music

Музыка обязательна. Инструментал без вокала, 100–120 BPM, ровный ритм.

Озвучки нет. Говорящей головы нет.

# Caption

Показываю, как настроить автопостинг в инстаграм. Всё делается в чате Claude Code, программировать не нужно.

Шаг 1. Заводишь Metricool и привязываешь инстаграм. Через него Claude Code и будет публиковать. Аккаунт нужен бизнес или креатор: с личного автопубликация не работает, это ограничение самого инстаграма.

Шаг 2. В настройках Claude Code подключаешь четыре коннектора: Metricool публикует, Todoist держит план тем, GitHub хранит материалы, Google Drive — фотографии. Это делается в интерфейсе, кода не нужно.

Шаг 3. Просишь Claude Code положить материалы в GitHub: утверждённый текст поста и правила тона. Фото можно оставить в Google Drive, он заберёт их оттуда. Дальше Claude Code берёт текст из репозитория, а не выдумывает заново.

Дальше пишешь одну фразу: «Собери карусель по брифу и опубликуй в инстаграм». Claude Code собирает, проверяет и публикует.

Мой закреп вышел именно так. Здесь я строю контент-завод и показываю, что в нём ломается по дороге.

# Acceptance criteria

- 36 секунд, 1080×1920, 30 fps;
- шесть кадров по шесть секунд;
- каждый шаг называет конкретную вещь, а не действие вообще;
- четыре коннектора названы поимённо;
- первый кадр и обложка говорят, что всё делается в чате Claude Code;
- действующее лицо на экране — Claude Code, а шаги сформулированы как просьбы к нему;
- финал говорит, что автор строит контент-завод;
- фраза из пятого кадра читается целиком и держится на экране;
- ни лица, ни голоса, ни говорящей головы;
- музыка присутствует, дорожка стерео;
- обложка читается в ленте без звука и не повторяет механику предыдущей;
- ни одного факта сверх подтверждённого списка;
