# Master brief — одна тема на три площадки

## Что реально произошло

Автор попросил Claude Code взять одну тему, сделать из неё материалы для Instagram,
Telegram и vc.ru и опубликовать. Этот прогон и есть тема. Материал описывает сам себя:
то, что читатель видит, — результат описанного процесса.

## Почему сейчас

Мультиканальный контракт проекта появился в репозитории 3 сентября
(`channels/multichannel-chrome-publishing.md`, `channels/telegram.md`). Это первый прогон
по нему. Пока опыт свежий и видно, что действительно сработало, а что нет.

## Подтверждённые факты

Всё проверено в этом прогоне, ничего не взято из общих соображений.

1. Источник фактов один — этот файл. Каждый канал получает свой текст, копипасты между
   каналами нет: это прямой запрет `channels/telegram.md` и мультиканального контракта.
2. Публикация в каналах устроена по-разному:
   - Instagram уходит через Metricool по API — так вышли закреп и рил 30 августа;
   - у vc.ru публичного эндпоинта создания записи нет;
   - Telegram и vc.ru остаются браузерными.
3. Про vc.ru API — что именно проверено. Три read-only прогона из GitHub Actions, без
   единой записи:
   - `api.vc.ru/v2.31` и `api.vc.ru/v2.1` живые, отвечают JSON;
   - `/v1.9` — 404, префикс выведен из эксплуатации;
   - `/subsite/subscriptions` — 200 без токена, чтение открыто;
   - `/subsite/me` — 401;
   - `/uploader/upload` — 405 на GET: эндпоинт существует и ждёт POST, загрузка файлов есть;
   - восемь путей создания записи (`/entry/create`, `/entry/new`, `/entry/draft`,
     `/entry/drafts`, `/entry`, `/entries`, `/writing/create`, `/writing`) — 404 на обоих
     префиксах.
   Ключевая деталь: тот же API отвечает 401 там, где дело в авторизации. Значит 404 здесь
   означает «такого пути нет», а не «не хватило токена».
4. Визуалы рисует рендерер проекта, не генератор картинок. Для статьи на vc.ru это обложка
   и три схемы, 1920×1080.
5. Рендер проверяется гейтами, которые роняют сборку: отрисованные слова должны совпадать
   с объявленными в манифесте; шрифты проекта должны быть реально загружены; подпись не
   должна вылезать из блока и из безопасной зоны; палитра — только утверждённая; размер
   холста — точный.
6. Гейты ловят не всё. Три дефекта в этом прогоне нашлись только глазами, при том что все
   проверки были зелёными:
   - у стрелок наконечники висели отдельно от древка;
   - черновик на обложке заполнялся снизу вверх;
   - баннер аккаунта на узком кропе терял заполнение — то есть весь свой смысл.
7. Человеческих решений остаётся четыре: тема, текст, дизайн, публикация.

## Что является мнением автора

- Что «три материала из одной фактуры» экономят силы — наблюдение по одному прогону,
  не измеренная величина.
- Что гейты полезнее ручной вычитки на технических ошибках — вывод из практики, не данные.

## Чего нельзя утверждать

- Что всё опубликовалось само. Финальный клик в каждом канале делает человек.
- Что vc.ru опубликован, пока он не опубликован. До этого — черновик.
- Любые цифры охватов, подписчиков и времени. Их никто не мерил.
- Что API vc.ru «закрыли» или «сломали». Проверено только то, что перечисленных путей нет.

## Основной тезис

Одна фактура превращается в три самостоятельных материала без переписывания с нуля.
Но последний клик и вкус остаются человеку, и в этом прогоне это видно буквально.

## Углы для каналов

- **Instagram** — короткая инструкция-результат: что получилось на трёх площадках и где
  всё ещё нужен человек.
- **Telegram** — рабочая записка: что сделал, что выяснилось про API vc.ru, что дальше.
- **vc.ru** — разбор: как устроен мультиканальный прогон, чем каналы отличаются, что
  ловят гейты и чего они не ловят.

## Ограничения по визуалу

Фирстиль из `brand-system.md` и `design-direction.md`. Без псевдоинтерфейсов, логотипов
сервисов и AI-иконок. Instagram-рил — семейство `instruction-cards`, без лица и озвучки.
