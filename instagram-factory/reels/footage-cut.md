# Нарезка рилса из съёмки

Существующие файлы в `reels/` — это motion-рилсы с кинетическим текстом, их собирает
`renderer/reels/cli.mjs`. Этот документ про другое: про talking-head, когда есть исходная
съёмка и из неё нужно достать куски, где автор говорит по теме.

Инструмент — `scripts/reel-cut.mjs`. Он работает только локально: нужны исходные видео на
диске и локальный whisper. В сессиях Claude Code на вебе шаги ниже не выполняются — там нет
ни сети до Google Drive, ни возможности поставить кодеки.

## Что нужно на машине

- `pnpm install` в `instagram-factory/` — оттуда берутся `ffmpeg-static` и `ffprobe-static`;
- whisper в PATH: `pip install -U openai-whisper` (или свой бинарь через `--whisper-cmd`);
- исходники, скачанные в отдельную папку, например `~/footage/tariffs/`.

## Шаги

### 1. Расшифровка

```
node scripts/reel-cut.mjs transcribe --input ~/footage/tariffs
```

Достаёт из каждого видео дорожку в 16 кГц моно и прогоняет через whisper. Результат —
`reels/.cut/transcripts/<имя>.json`. Шаг долгий: на модели `medium` это примерно реальное
время записи. Модель меняется через `--model` (`small` быстрее и заметно хуже на именах и
числах, `large-v3` точнее и медленнее).

Шаг идемпотентный по файлам, но расшифровку не кеширует: повторный запуск считает заново.

Если расшифровка уже есть из другого инструмента — Premiere, MacWhisper, что угодно, —
этот шаг можно пропустить. Положи файлы в `reels/.cut/transcripts/` в формате `.srt` или
`.vtt`, назвав их по имени исходного видео: `IMG_0611.srt` рядом с `IMG_0611.MOV`. Когда на
один исходник есть и `.json`, и субтитры, берётся `.json`.

### 2. Поиск фрагментов

```
node scripts/reel-cut.mjs find --input ~/footage/tariffs
```

Ищет в расшифровках сегменты по основам слов — `тариф` ловит и «тарифы», и «тарифов».
Соседние совпадения (ближе `--gap`, по умолчанию 2 секунды) склеиваются в один фрагмент,
границы расширяются на `--pad-before` и `--pad-after`, слишком короткие отбрасываются
по `--min-duration`.

Свой список тем задаётся через `--keywords`:

```
node scripts/reel-cut.mjs find --input ~/footage/tariffs --keywords тариф,прайс,ставк
```

На выходе два файла:

- `reels/.cut/candidates.md` — читаемый список с таймкодами и текстом;
- `reels/.cut/edl.json` — черновой монтажный лист.

### 3. Отбор

Это ручной шаг, и он же главный. Поиск по словам находит все упоминания темы, а в рилс
идут только те, где мысль звучит целиком и убедительно: есть законченное утверждение,
нет запинки в начале и обрыва на середине фразы.

В `edl.json` нужно:

- поставить `"use": true` тем фрагментам, которые идут в ролик;
- расставить их в нужном порядке — фрагменты режутся в том порядке, в каком лежат в массиве;
- поправить `start` и `end` по таймкодам, если границы фразы съехали.

Первым ставится самый сильный фрагмент: в Reels решают первые секунды, а не разгон.

### 4. Сборка

```
node scripts/reel-cut.mjs cut
```

Каждый фрагмент кадрируется в 1080×1920, приводится к 30 fps, звук выравнивается по
громкости до −14 LUFS. Дальше всё склеивается без перекодирования в
`reels/.cut/reel.mp4`. Путь меняется через `--output`.

Если готовый ролик длиннее 90 секунд, скрипт предупредит: Reels столько не берёт.

## Границы инструмента

`reels/.cut/` не коммитится — там лежат исходники, промежуточные куски и результат.

Скрипт не делает субтитры, обложку, музыку и перебивки. Он собирает черновой монтаж из
речи, дальше ролик доводится вручную.
